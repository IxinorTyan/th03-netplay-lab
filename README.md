# TH03 双语单机与双人对战

2026-10-08 移动端优化已接入原有单机、本地双人和联机入口。请完整更新 `web/`（包含新增的 `np21-mobile.wasm`、`np21-rollback-mobile.wasm` 和版本清单），双方刷新后再联机。原版 WASM 保留用于浏览器兼容回退。构建说明见 `tools/mobile-runtime/README.md`。

基于 NP21 WASM 运行《东方梦时空》，提供中文汉化／日文单机、本地双人和双人网络对战。当前说明对应 2026-10-08 版本，联机协议为 `th03-rollback/2`。

仓库上传的是可直接运行的分发版本，包含网页、游戏镜像、运行资源、服务端和启动器，不需要构建工具。开发源码、构建产物、报告和截图留在维护者本地。

网页沿用 TH04 的布局：首页四个模式入口，联机页分为房间外的创建／加入界面和房间内的准备大厅。TH03 保留自己的双人对战规则，角色在原生游戏内选择。

## 启动

需要 Python 3.10+ 和支持 WebAssembly、gzip 流解压的现代 Edge／Chrome。使用完整的随附 `web/` 资源即可运行，无需先构建；请通过启动器访问，不要直接双击 HTML。

| 模式 | 启动方式 | 页面与说明 |
| --- | --- | --- |
| 单机游戏 | `start.bat`，首页选择“单机游戏” | `solo.html`，保留原版开头、菜单和剧情 |
| 本地双人 | `start.bat`，首页选择“本地双人” | `local.html`，一台设备操作双方 |
| 局域网联机 | `start-lan.bat` | `lan.html?network=lan`，默认端口 9869 |
| 公网联机 | 部署房间服务或启动临时公网隧道 | `lan.html?network=public`，双方访问同一个公网入口 |

本地服务器只监听本机，默认地址为 http://127.0.0.1:9868/ ，端口被占用时向后寻找可用端口，以窗口输出为准。手机访问请运行 `start-lan.bat`，打开窗口提供的局域网地址，再从导航进入所需模式。Windows 防火墙需允许 Python 接收入站连接。

首页的联机卡片不会启动后台房间服务；联机需使用 `start-lan.bat` 或已部署的公网服务。原来带 `net=rtc`／`net=relay` 的 `index.html` 链接会保留参数并跳转至 `local.html`。

使用 WebSocket 转发前运行一次 `install-relay.bat`。临时公网测试还需要可从 PATH 调用的 cloudflared：保持 `start-lan.bat` 运行，再启动 `start-public-tunnel.bat`，双方打开窗口提供的同一个完整链接。Quick Tunnel 重启会换地址，关闭窗口后链接失效。

部署与排障见 [Relay 使用及部署说明](README-RELAY.md)；TURN 配置、临时隧道与凭据接口见 [公网联机说明](README-PUBLIC.md)。

## 单机与游戏语言

单机、本地双人和联机均可选择中文汉化或日文版；网页操作界面保持中文。单机／本地双人在启动前选择语言，网络房间由房主统一选择，全员自动跟随；开局后需要结束游戏才能切换。

单机使用原始 NP21 核心与 `3-cn.hdi.gz`／`3-jp.hdi.gz` 对应资源，保留标志动画、标题、选人、剧情、音乐和原版暂停，不安装双人直达选人、全角色解锁或音乐替换。难度在原版菜单内选择。

单机的 `np21-solo.js` 适配器缓存已审计的静态函数表查询，原版 WASM、时钟、主循环和音频保持不变。同机日文单机战斗的单次对照中，平均模拟器回调耗时从约 12.6 ms 降至 8.1 ms；这是桌面测量，不代表手机保证。更新时需包含 `web/vendor/np2/np21-solo.js`、`solo-runtime.json` 和 `web/solo-performance.js`。

手机单机卡顿时，可进入实际战斗，打开“按键与触控”，点击“记录性能（15 秒）”，退出面板继续游玩，然后再次打开面板“下载性能报告”。记录期间避免暂停、切换页面或关卡。报告包括浏览器、模拟器配置、回调耗时和游戏推进速度，只下载到本机，不自动上传；回调次数不能当作游戏 FPS。平时不运行记录循环。

单机保留触摸操控，并提供四个独立、默认关闭的可选辅助：

- 启用低速模式。
- 低速时显示判定点。
- 触摸模式一直显示判定点。
- 触摸不限速移动。

辅助仅作用于 Story／1P VS CPU 的人类玩家，不影响 CPU、演示或结算；不限速仍限制在原生场地内。连发和蓄力使用独立按钮；只有按住连发键才连续射击。单机设置与双人模式分别保存。

## 本地双人与暂停

启动前选择语言、难度和 CPU，点击“启动游戏”后跳过标志动画，直接进入 **1P VS 2P 双人选人**。全九名角色开放，已有排行榜姓名、分数等记录保留。难度为 Easy／Normal／Hard／Lunatic，默认 Normal；CPU 倍频不等于游戏帧率。

| 操作 | 本地 1P | 本地 2P |
| --- | --- | --- |
| 移动 | 方向键 | WASD |
| 连发（点按单次，长按每秒5次） | Z | J |
| 蓄力（按住） | Shift | K |
| 攻击／取消 | X | L |
| 按住低速 | 空格 | 左 Ctrl |
| 打开自己的暂停菜单 | Esc | Backquote（`~` 所在的键） |

“操作设置”可修改双方键位及手柄分配，Esc 和 Backquote 为保留键。标准手柄方向键／左摇杆移动，A 连发，X 蓄力，B 攻击，RB／R1 低速，Start 暂停；手柄可能需要先按键激活。

任意一方暂停会冻结整场，由打开菜单的一方用自己的方向键、确认／取消键操作，也可直接点击选项。暂停菜单跟随游戏语言：

| 中文 | 日文 | 行为 |
| --- | --- | --- |
| 继续 | 再開 | 继续当前对局 |
| 本局认输 | ラウンド降参 | 当前玩家输掉本局，按原版规则进入下一局或结束整场 |
| 背水阵 | 背水の陣 | 当前玩家输掉整场，保留原版算分和对手胜利 CG |

这些菜单用于双人对战；单机仍使用原版暂停。双人选人界面按一次 Esc 提示退出，1 秒内松开再按一次关闭游戏；长按不触发退出。正常算分和胜利 CG 后回到双人选人。

全屏下短按 Esc 用于暂停／继续；支持的浏览器会锁定 Esc。若浏览器仍强制退出系统全屏，游戏保留铺满网页的布局并暂停。退出布局请点击右上角全屏图标。暂停菜单支持点击、方向／绑定键、Tab、Enter 和空格；点击空白处或重新切回窗口后仍可用键盘操作。

## 触摸与操作辅助

触控支持拖动移动、第二指按住低速、连发／蓄力／攻击／暂停按钮，以及原版菜单所需的方向和确认按钮。“按键与触控”提供灵敏度、双击同一位置攻击、全屏、自定义按键位置／大小／层级；横竖屏布局分别保存。

所有模式已取消自动开火。触屏使用独立的“连发”和“蓄力”按钮：连发点按单次、长按每秒5次（60帧下每12帧一次），蓄力按住持续、松手释放；同时按住时优先蓄力。普通拖动受角色当前速度限制，低速减半；可选“触摸不限速移动”允许更快拖动，仍受场地边界限制。

房主可在开局前设置“允许触摸不限速移动（双方）”。关闭后双方均按角色速度移动，即使浏览器此前保存了不限速偏好也不能启用；设置修改后双方需重新准备。连发与蓄力按钮均可调整位置、大小和层级，横竖屏分别保存。

低速与判定点的作用范围：

| 选项 | 单机／本地双人 | 联机 |
| --- | --- | --- |
| 启用低速模式 | 在本机操作设置中调整 | 房主统一控制双方，开局后锁定 |
| 低速时显示判定点 | 当前浏览器保存 | 只改变自己的浏览器画面 |
| 触摸模式一直显示判定点 | 触摸模式启用时生效 | 只显示本机座位，不要求按住低速 |
| 触摸不限速移动 | 可选拖动辅助 | 房主允许后由本机选择；关闭许可时双方强制限速 |

判定点在浏览器覆盖层绘制，不修改游戏碰撞范围，不写入模拟器显存，也不会改变另一位玩家的显示开关。本地双人低速／低速判定点默认开启，单机四项辅助默认关闭。

修改触摸布局会释放输入，但不会自动暂停游戏。需要停下时先暂停再调整。浏览器可能不允许远端开局事件触发系统全屏，可主动点击全屏按钮。

## 房间与联机

1. 双方打开同一个房间服务地址；房主创建房间，分享四位房间号或邀请链接。
2. 房主可在“房主席位”选择左侧 P1 或右侧 P2，客机自动分配到另一侧。更换席位后双方需重新准备，开局后席位固定。
3. 房主选择语言、难度、CPU、“启用低速模式（双方）”和“启用回滚”。修改后双方需要重新准备。
4. 双方准备后由房主开始，游戏在房间页内自动加载，显示双方加载进度，再进入原生选人。

联机双方均使用自己浏览器的 **1P 键位**（方向键、Z、Shift、X、空格、Esc），系统将输入映射到各自选择或分配的席位；不接受本机 P2 键位来操作对手。触摸、手柄和暂停菜单也跟随席位。

各端运行自己的模拟器，只交换输入与同步消息，不传输画面或声音。连接设置提供 WebRTC 设备直连／TURN 和 WebSocket 服务器转发。公网自动模式的 TURN 兜底需另行配置；Relay 无需 TURN 账号。

**所有网络模式默认关闭回滚**，等待双方确认输入后推进；房主可在开始前开启回滚，以额外快照和重算开销换取更及时的本地响应。策略由房间设置决定，客机个人设置或 URL 不能覆盖。网络抖动、慢设备和标签页后台限速都可能使对局等待。

启动时校验两端资源版本，运行中交换同步校验。断线、版本不一致或同步错误时按页面提示结束并重新建房；暂不支持断线续局。切换连接方式也需重新建房。

## 存档与更新

中文／日文存档分别保存到当前浏览器 IndexedDB；原版单机使用独立的 `th03-original-solo` 数据库，与本地双人、TH04 及旁边的 `touhou-np2` 项目隔离。支持按语言导入／导出 HDI，导入在启动前进行。单机保存与导出会恢复原始 MAIN.EXE，保留原版存档兼容性。

联机使用统一初始镜像，不读取或覆盖单机进度。清理浏览器数据、更换浏览器或访问端口会改变存档访问范围，请先导出备份；避免同语言版本在多个页面同时运行。

更新时停止旧服务，将同一版本的完整 `web/` 和服务端文件一起替换，再重启服务。双方刷新网页并重新建房；仅在已运行的模拟器内“重启”不会载入新的网页代码和原生补丁。

## 上传与分发

`.gitignore` 使用根目录白名单，只纳入可直接运行的分发文件。分发包应保留：

- 完整 `web/`，包括页面、样式、背景、`web/disks/3-cn.hdi.gz` 与 `web/disks/3-jp.hdi.gz`、原生辅助、音乐、字体、模拟器 JS／WASM、许可证和版本清单。两张磁盘是运行必需资源。
- 本地入口 `server.py`、`start.bat`。
- 联机服务 `lan_server.py`、`relay_server.py`、`turn_service.py`，以及 `start-lan.bat`、`requirements-relay.txt` 和 `install-relay.bat`。
- 公网隧道及 TURN 配置入口 `public_tunnel.py`、`configure_turn.py`、对应启动器和 `README-RELAY.md`、`README-PUBLIC.md` 使用说明。

`tools/`、`patches/`、`reports/`、`build/` 和 `DEVELOPMENT.md` 是维护资料，不属于分发包。直接压缩整个工作目录不会应用 `.gitignore`；Git 也会继续打包已跟踪的文件，即使它们后来被忽略。提交前检查 `git status --short` 和 `git ls-files -ci --exclude-standard`，确认新增跟踪内容符合分发范围。忽略规则不会删除本地文件。本机 TURN 凭据、临时公网网址、日志及缓存不会作为未跟踪文件上传。

## 验证与维护

已完成桌面／手机视口布局、真实双端联机启动、Relay／WebRTC 同步回归、中日文单机剧情载入与触摸辅助、存档导出及磁盘审计。真实手机触摸手感、跨 NAT 打洞、正式 TURN 账号、公网延迟和长时间对局仍需实际设备验收；本机测试不代表公网性能保证。

游玩无需运行构建工具。维护者修改代码或资源后，需重新生成相关资源及同步清单；构建方法和测试入口见 [开发记录](DEVELOPMENT.md)。其中历史记录描述当时状态，当前功能以本说明为准。

若启动时报“同步资源校验失败：player-ui.js”（或其他文件名），说明部署文件与 `web/lockstep-runtime.json` 的指纹不一致。仅修改网页脚本等现有资源时，维护者可运行 `python tools/build_lockstep_runtime.py --fingerprints-only` 更新清单，再运行 `node tools/audit_assets.mjs` 检查全部联机资源；改动模拟器构建逻辑时仍需完整构建。将资源与清单一同分发后，双方刷新页面并重新建房。

NP21 许可证见 `web/vendor/np2/LICENSE`；游戏及汉化资源来自用户提供的本地整合包。

联机自定义操作：游戏中打开“操作设置”，或在全屏的“按键与触控”内点击“自定义键盘 / 手柄”。可修改本机键盘绑定、选择手柄、重设手柄按钮；设置自动保存，局域网与公网共用，独立于本地双人配置，不受左右席位影响。手柄左摇杆固定移动，默认 A 连发、X 蓄力、B 攻击、RB 低速、Start 暂停。浏览器手柄 API 需要 HTTPS 或 localhost，普通局域网 HTTP 地址可能无法使用手柄。
